# IoT-Based Smart Irrigation Monitoring System

## Project Overview
This project focuses on developing a smart irrigation monitoring system using ESP32-C3 and a capacitive soil moisture sensor, with an RF energy harvesting approach.

## Objectives
- Monitor soil moisture levels.
- Process sensor readings using ESP32-C3.
- Develop an automated irrigation control mechanism.
- Explore RF energy harvesting for low-power applications.

## Hardware Components
- ESP32-C3
- Capacitive Soil Moisture Sensor
- Microstrip Patch Antenna
- RF Rectifier Circuit
- Relay Module
- DC Water Pump

## Technologies Used
- Embedded C / Arduino IDE
- ESP32-C3
- RF Energy Harvesting
- IoT
- Sensor Interfacing

## Working Principle
1. The antenna receives ambient RF signals.
2. The rectifier converts received RF energy into DC voltage.
3. The energy storage stage is designed to store harvested energy.
4. ESP32-C3 reads soil moisture values.
5. The controller processes the sensor readings.
6. The irrigation control mechanism operates according to the configured moisture threshold.
